Backing up and changing the layout

The layout lives in the keyboard's memory, so it works on any computer without software. To change it, use hhkb_q60.py from the Q60_HHKB repo, or VIA. Either one first needs permission to talk to the keyboard.

Allow access (once per plug-in)

Linux only lets root write to the keyboard's settings interface. This grant lasts until you unplug the board.

sudo chmod a+rw /dev/hidraw9

The number can change after replugging. To make access permanent and let VIA in Chrome connect too, add a udev rule instead:

echo 'KERNEL=="hidraw*", ATTRS{idVendor}=="3434", ATTRS{idProduct}=="01c0", MODE="0660", TAG+="uaccess"' \
  | sudo tee /etc/udev/rules.d/99-keychron-q60.rules
sudo udevadm control --reload && sudo udevadm trigger

Save a backup

Writes every layer to a timestamped JSON file in the current folder.

cd Q60_HHKB
python3 hhkb_q60.py backup

Restore a backup

Every apply saves a backup first, so to undo it, restore the backup that run made.

python3 hhkb_q60.py restore q60_backup_<timestamp>.json

Apply the HHKB layout again

Saves a backup first, then writes the layout and reads it back to confirm.

python3 hhkb_q60.py apply

Edit single keys in VIA

Open usevia.app in Chrome or Chromium, click Authorize device and pick the Q60. Layers 0 to 3 in VIA match this page: 0 Mac, 1 Windows, 2 Fn, 3 Fn + Right Shift. Changes save to the board as soon as you make them.

Layout written over VIA protocol 0x000B. Layers 4 and 5 are empty and free for your own use.
