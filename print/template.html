Backing up and changing the layout

Allow access (do this first)

Linux only lets root write to the keyboard's settings interface. This udev rule gives your user access every time the board is plugged in, and lets VIA in Chrome connect:

echo 'KERNEL=="hidraw*", ATTRS{idVendor}=="3434", ATTRS{idProduct}=="01c0", MODE="0660", TAG+="uaccess"' | sudo tee /etc/udev/rules.d/99-keychron-q60.rules
sudo udevadm control --reload && sudo udevadm trigger

Quick one-off alternative, lost on every replug or reboot: sudo chmod a+rw /dev/hidraw9

Script commands

python3 hhkb_q60.py backup             # save every layer to q60_backup_<timestamp>.json
python3 hhkb_q60.py apply              # back up (never overwrites), write HHKB layout, verify
python3 hhkb_q60.py restore FILE.json  # write a backup back

Edit single keys in VIA

Open usevia.app in Chrome or Chromium and authorize the Q60. Layers: 0 Mac, 1 Windows, 2 Fn, 3 Fn + Right Shift, 4 and 5 free.
